## Reviewer Instructions

For each record, select:

- **Certify:** Access remains necessary and appropriate.
- **Revoke:** Access is no longer required.
- **Modify:** Access remains necessary but must be changed.
- **Escalate:** Additional information or authority is needed.
- **Suspend:** Access should be restricted during investigation.

Do not certify access solely because the user had it during a prior review.
